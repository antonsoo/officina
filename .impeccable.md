# Design context

The owner's public portfolio is for curious learners, engineers, founders and
prospective collaborators. Visitors need a few concrete places to begin and a
searchable index of the rest. The owner explicitly requested a substantial
redesign on 2026-10-29: avoid generic project cards and job-title/location copy;
use Anthony Mercer and links to GitHub and PRAVIEL.

The direction is a printed index of working experiments. Large, unornamented
serif type carries the questions; compact sans-serif type carries navigation and
records. Olive ink and a pale neutral ground, ruled sections, no card shadows,
no badges, no decorative dashboard statistics. One large visual introduces a
specific operated experiment. Three shorter selections span music, mathematics
and software. The complete catalogue uses rows with source and review links.

Use actual app views. Keep the existing search, source terms, explicit sharing,
keyboard focus, load recovery and light/dark operation. On phones the selected
work stacks and the project index remains readable. Existing search URLs should
land at the index, bypassing the longer introduction.
