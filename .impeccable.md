# Design context

The showcase owner's house brief identifies this catalogue as a public portfolio
for engineers, founders and prospective clients. The owner asks for distinctive,
consequential learner work and rejects generic filler. The catalogue's job is to
connect a visitor's concrete interest to a working tool and recorded evidence.

## Use case for this change

A visitor searches a source word, finds one particular workshop in a larger
repository and needs to understand what that workshop lets them do. Its title,
summary, screenshot and review should describe the same activity. An unrelated
umbrella-project screenshot or finding makes that decision unnecessarily hard.

## Design direction

Preserve Officina's existing cream, red and serif identity and mounted native
search controls. Treat a matching workshop as an editorial entry with a concrete
learner action and a pinned review. Use actual screenshots, explicit links and
plain language. Keep typing local and provide explicit Copy search link. A
visitor should retain keyboard focus and get a usable phone-width result.
