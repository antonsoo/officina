live-demo link opens the real filesystem dependency comparison: the same server
and reported version lost declared fields in 13 tool schemas when Zod changed.

layout changes. The immutable evidence links identify source revisions;
registry links retain their separate release boundary.

builds and passes all 32 existing Chromium/Firefox browser scenarios. Local
lint, types, formatting and catalogue validation also pass. Pages `f92f482`
preserves old hashed assets and changes only `projects.json`. All 40 canonical
served files match the [clean-build inventory](hosted-bytes.json).

focus and horizontal fit with no subsequent requests or page errors: 16 card
views per phase. [Local](local/browser.json) and [public](public/browser.json)
receipts keep these browser claims separate from served-file verification.
