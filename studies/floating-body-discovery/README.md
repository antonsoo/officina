# Floating-body discovery

This study connects catalogue words to the actual public Zygon floating-body
experiment and its immutable direct review. It retains the original balance's
primary project route.

- `search.mjs`: eighteen source/model/normalization queries, with direct row/link
  checks and warm-page offline refiltering in four browser configurations.
- `local-search.json`: observed local catalogue searches against the final metadata.
- `local-journeys.json`: search -> actual public controls/source frame -> immutable review heading.
- `build.json`: clean archive installation, required checks and built-file identity.
- `hosted-files.json`: canonical public build bytes.
- `hosted-search.json`: actual public searches and offline refiltering.
- `hosted-journeys.json`: actual public continuous navigation journeys.
- `publication.json`: source/static branch identities and bounded publication claims.
- `preserved-assets.json`: all 28 preceding static asset URLs, checked against
  their original bytes after publication.

The local workflow captures are in `docs/assets/floating-body-discovery/`.
The physics and source evidence belong to Zygon's separately recorded review;
these discovery observations do not validate physical buoyancy or translations.
