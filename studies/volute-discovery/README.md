# Finding the Ionic compass desk

Search **minuatur**, **oculus**, **Vignola** or **Ionic volute** in the catalogue.
The matching row links directly to Gonia’s operated compass desk and an immutable
review of what its learner can do. The project card also features the new room;
its existing fluting, entasis, building-accounts and Babylon routes remain.

The actual public Gonia bench was captured at the completed twelve-pin state,
then cover-fitted to 1200 by 750 for the 38 KB WebP. It is a screenshot, not a
reconstructed capital. The initial lesson link starts with the first four arcs
so readers can choose and draw the remaining pins themselves.

## Local journey

The [recorded review](local-journeys.json) follows the actual catalogue search,
keyboard link, twelve keyboard compass arcs, endpoint/tangent distinction,
unchanged outline under the local intervention, verified whole source plate,
and immutable GitHub review heading. Chromium and Firefox each passed at 1280
and 375 pixels, without document overflow or application errors. These checks
used the local catalogue and the already published lesson/review.

Run against a built catalogue:

```sh
node scripts/workshop-journeys.mjs CATALOGUE_URL OUTPUT volute
```

The [Gonia publication record](https://github.com/antonsoo/gonia/blob/0d78aa24509f87b2fc3a9965473e3a73d522d29b/docs/volute-publication.md)
separately verifies its public bytes, actual downloads and offline use.
