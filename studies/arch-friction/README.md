# Contact is not enough: discover the arch friction experiment

Search for **arch friction**, **Coulomb**, **sliding base**, **coagmenta** or
**latiores**. The existing arch workshop keeps its canonical route while its
pinned review now includes the finite-friction work. The source term continues
to lead to the actual experiment, rather than merely to a project homepage.

1440/375 px. They explicitly redirect the future canonical route to the reviewed
build and render the pinned review from Git. The learner repairs a trial at
mu 0.65, finds no possible path at 0.60, changes width without changing base
friction demand, repairs that demand with pier weight, and reads the actual
retained Latin source page. An actual browser capture supplies the thumbnail.
