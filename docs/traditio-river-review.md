# Find the river history through its Latin condition

The Traditio river lesson is discoverable through `alluvion`, `avulsion`,
`ex eo tempore`, `haec pars tua manet`, `radices egerint` and `Roman river law`.
Its catalogue row opens the actual river bench. The earlier ownership and
formal-conveyance workshops retain their own routes and source reviews.

The recorded review pins Traditio source
`885ba4c0274cd09b4079012e060a079185ea4724`. It includes the primary-source mapping,
the model's limits, and the phone-overflow and edition-upgrade failures found by
a second audit. The thumbnail is an actual operated view: the parcel has arrived
and adhered for a long time, but roots have not entered the receiving estate.
The selected Digest model therefore still reports Lucius.

## Operated discovery

The driver searches every phrase, copies and reopens the explicit search link,
then follows both the pinned review and the lesson by keyboard. Typing alone
keeps the address bar unchanged. The raw review bytes must equal the pinned Git
blob before the journey continues.

In the lesson, new roots leave the short Institutes reading unresolved. The
fuller Digest passage supplies the additional conditions. With roots and long
attachment, Aulus acquires in the model; returning to arrival still shows Lucius.
The learner keeps that original ending and branches from arrival, then establishes
long attachment without new roots. The comparison identifies rooting as the sole
physical fact that differs under the same selected passages. This is an invented
conditional experiment, not a dated account of a change in Roman law.

The journey reads `ex eo tempore`, verifies the complete printed page 644 by
its image bytes, and saves actual JSON, every-point CSV, SVG and illustrated
HTML. Both histories and the learner's explanation are checked. Reopening the
HTML with scripts disabled needs no HTTP request; its native JSON download
reopens the same work. All four source images, both fonts and all license/source
notice bytes are checked. The raw HTML retains the Source Sans license's CRLF
bytes; its browser-rendered text follows HTML's normal newline normalization.

## Repeat the review

Run from the catalogue checkout, beside Traditio, after building the catalogue:

```sh
node scripts/traditio-river-journeys.mjs http://127.0.0.1:4502/officina/ test-results/river-local
```

The supplied origin must serve the production catalogue. The lesson and pinned
review remain public URLs; requests are not redirected to the local lesson.
Publication of the catalogue itself is a separate verification boundary.
