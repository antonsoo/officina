# Gnomon: a complete readable standing scale

The zodiac option omitted Scorpio and Pisces and engraved separate
solstice/equinox and zodiac labels over one another. Small high-latitude
drawings crowded still more labels. The missing pair now uses the existing
approximate -11.5-degree convention; coincident or crowded standing points
use lettered thin ticks, leaders and a wrapped printed key.

[Actual former drawings, corrected output and replay](https://github.com/antonsoo/gnomon/tree/main/studies/calendar-scale)
retain all twelve signs. Across 48 authored drawings and two native font
renderers, 730 overlapping label pairs, 96 missing sign labels and four clipped
hour labels become zero. This is a deliberate size/latitude stress matrix,
not an estimate of how often users encounter the defect.

An independent XML reader and ecliptic-vector rotation check 288 actual
serialized sign positions. Maximum declination difference is 0.0548 degrees,
including the existing approximate table and native rounding. Seventy-two
pole placements explicitly collapse at printed precision. All prior raw
calendar positions, native hour dots, ellipse geometry and selected-date
rings remain unchanged. Seventy-two non-zodiac polar SVGs and 16 complete
ordinary analemmatic SVGs retain their exact bytes; eight crowded ordinary
label layouts intentionally change.

Correction `14cdc07` passes from a fresh archived Node 24.21.0 installation:
lint/type checks, 313 unit checks in each of two number locales, build,
independent native replay and 76 actual browser workflows complete with
exit 0. A prematurely terminated chained check is explicitly excluded from
the accepted evidence.

Source `3006797` and Pages `423e161` publish that build. All 33 built files and
the canonical root match public bytes. Four public Chromium/Firefox
desktop/mobile contexts disconnect, open the same Sydney file and complete
20 actual downloads. All eight SVGs and eight original/edited portable inputs
match the clean local capture; zodiac-off SVGs also match the former designer.
All public designer and reopened-vector screenshots match reviewed local ones.
Four actual public PNGs contain all 28 expected calendar positions within
0.38 pixels of independent predictions. Their decoded RGB pixels are identical
to local downloads even where Firefox's PNG container bytes differ.
[Publication and pixel receipts](https://github.com/antonsoo/gnomon/blob/main/studies/calendar-scale/publication.json).

The sign-entry values remain approximate; the open ring supplies the selected
civil minute's position from the existing ephemeris. No new astronomical model,
physical fabrication, field observation or registry release is claimed.
