# Choose a question before opening a project

The opening selection previously put one large architecture feature above three
independent prose blocks. Reading the starting points required a long scroll,
especially on a phone. Its replacement selects five specific questions, with one
actual workshop preview and action/evidence links visible at a time. The
complete searchable index remains below it.

Keep Officina's moss palette and retained EB Garamond / Hanken Grotesk: paper
`#f4f3ec`, sheet `#e8e9df`, ink `#252c27`, moss `#35533d`, rule `#c2c7ba`.
Use a vertical menu like a game's scenario selection and a quiet preview window.
The selected question gets a substantial side marker and an actual selected
state. No decorative levels, coordinates or scores. Left-align text and let the
selected screenshot do the visual work; avoid numbers that imply a sequence.

On phones a native select exposes the same choices without a long stack of
buttons. Desktop keyboard users get a vertical tablist, arrows, Home and End.
Switching questions stays local and preserves search. Review the result at
375px and on desktop in both existing themes and browsers.

Choices point to existing published routes. Horos's new conditional room is
not advertised as hosted. Review/source links come from the validated catalogue;
the menu makes no new claim about their editions. HOUSE_STANDARDS.md leaves
publication for review.
