# Finding the acts of a Roman conveyance

Traditio's companion lesson is discoverable through `libripens`, `praeterea alio`,
`negante aut tacente`, `in iure cessio` and `bronze and balance`. The workshop is
called “Five witnesses, and another person.” It opens the actual ceremony page;
the existing counterexample workshop remains available.

Its review pins source `6d7fa829d2579a20e4776f59a59907070b34c16e`, including the
source mapping and concrete exercise. The thumbnail is a public screenshot after
Aulus has made the first claim with five witnesses and an additional balance
holder; civil title still belongs to Lucius at that stage.

The discovery driver searches all five phrases, explicitly copies and reopens a
search link, follows the pinned review by keyboard and compares its raw public
bytes with the Git blob. It then follows the lesson, checks the four-witness
failure, enters the magistrate sequence and verifies that a disclaimer still
awaits the award. It displays and hashes printed page 134 and downloads the same
4,571,494-byte illustrated rehearsal independently reviewed in Traditio.

The local catalogue-to-public-lesson journey passed in Chromium and Firefox at
1440 and 375 pixels. Editing the search does not rewrite the address bar.

The clean Node 24.22.1 build from `00798bbcb908f61cb2274a6c4ae24d0a120e0675`
contains 91 canonical files, identical to the working build. Deployment
`10f8f1d3cdcec324c748a0a00a11c075eb2e0c28` serves those bytes. The complete
canonical inventory and root aliases matched before and after the four public
catalogue journeys. All four reached the pinned review, operated the actual
lesson, verified the page-134 image and downloaded the identical rehearsal.

The thumbnail was independently fetched from Traditio's public Git blob at
`4222fed51ceb6d0dea91dea11eef33518054b8fe` and from this public catalogue.
Both equal the 143,012-byte captured image, SHA-256
`43d1bd2e817f9ac0be25d34c8b9631607e45891a721b2765c7951a8677d59665`.
Byte-identical public screenshots reuse the retained local captures; distinct
images remain in the public directory.

Pages reports legacy publication from `gh-pages`. No Actions runs for the generated
catalogue deployment were returned in the recorded query. This is not a CI-success
claim; build, public bytes and actual browser operation are separate receipts.
