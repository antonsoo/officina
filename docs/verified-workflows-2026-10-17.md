The native reader owns metadata validation. Cohort filtering keeps it aligned
through reordered rows, exclusions, clusters and repeated generations. Known
question, grader name/configuration/value and direction conflicts block
inference. Missing declarations remain unchecked. Matching fingerprints do
not verify scorer code or hidden settings. After a rejected browser upload,
the pair tab names the last valid comparison file and retains its direction.

The clean native/standalone pipeline passed 220 root Python tests and 226
standalone-bundle tests, plus lint, strict mypy, TypeScript and static builds.
The logged-out public replay verifies all 27 Errorbars manifest files and the
immutable card, then disconnects before analysis. Both browser engines verify
rank direction, conflict recovery and real JSON downloads. Eight public
metadata captures match the inspected local images byte for byte.

At the 20,000-row demo limit, an eight-model, 1,250-question replay retains all
means and 28 adjusted p-values. Median full native workflow time is 1.379 s
before and 3.105 s after on the shared 14-vCPU WSL2 Linux host with 48 GB RAM.
The additional evidence checks have a cost. This is not a worst-case bound or
browser latency estimate. [All timings and hashes](assets/verified-workflows-2026-10-17/metadata-scaling.json).

The root workbench Git workspace has no remote. Its source commits are local;
the deployed static bundles, authored cards and runtime archives are public
