# A fixed inclination, a moving observer

The Gonia card opens the new
[viewpoint experiment](https://antonsoo.github.io/gonia/optics.html?d=300&h=120&e=16&l=40&a=48&mode=source&read=4#vp-workshop)
with Vitruvius's “plumb and square” clause selected. Its evidence link reaches
the [direct learning review at 65e8138](https://github.com/antonsoo/gonia/blob/65e813814ed992b3efa1b8ee53adbab6e2602681/docs/optics-review.md#what-a-learner-can-do).
The catalogue still contains 29 projects; this is the tenth room of an existing
project, not an additional catalogue entry.

| Learner's choice                                             | Observed geometric result           |
| ------------------------------------------------------------ | ----------------------------------- |
| Keep the source's 1:12 slope at the chosen 30 m distance     | Upper endpoint ray is longer        |
| Find the equal-ray view, with face centre 12 m and eye 1.6 m | Horizontal distance becomes 124.8 m |
| Move one decimetre farther without changing the slope        | Upper endpoint ray becomes shorter  |

The viewing distance and equal-ray criterion belong to the modern model.
Vitruvius supplies the inclination prescription and makes a claim about
appearance; the card does not turn that claim into a validated perceptual result.
The complete application adds six Latin passages, contextual notes, two Greek
companion words, four full edited pages, an original museum photograph and a
script-free illustrated reading.

Before this change, actual hosted searches for `one twelfth`, `perpendiculum`
and `sight lines` returned no card. The [before receipt](../studies/viewpoint/before.json)
retains those results. The twenty older search terms remain, including hoists,
sounding vessels, column geometry and theatre plans. The new thumbnail is an
unedited native viewport of the hosted workshop; its
[capture receipt](../studies/viewpoint/thumbnail.json) records the URL and method.

The [native replay](../studies/viewpoint/replay.mjs) checks five queries, search
focus and URL preservation, the decoded thumbnail, actual keyboard navigation
to the hosted lesson, the equal-ray operation and reversal, and the selected
Latin clause. It then returns to the catalogue and reaches the intended heading
at the pinned GitHub source by keyboard. Chromium and Firefox run at desktop
and phone widths. Search makes no extra catalogue request.

Catalogue source, clean-build identity, canonical hosted files and actual
hosted routes are recorded separately. The application's own primary-source,
model, artifact, offline and publication records remain in Gonia. No registry
release or CI run is inferred from this metadata update.

The [local operated replay](../studies/viewpoint/local-replay.json) covers all
four browser/width configurations. The [Node 24 clean archive](../studies/viewpoint/build.json)
passes install, lint, formatting, forty tests and build, with all 61 static
files byte identical to the reviewed Node 26 output. Both retained local
screenshots were opened and visually inspected.
