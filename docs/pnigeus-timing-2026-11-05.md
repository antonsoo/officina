# A direct route to the water-organ timing problem

The Pnigeus shape study remains its main catalogue route. A second workshop,
**Must you spend all your air?**, opens the one-pipe timing experiment with
seven strokes placed at the start. The thumbnail is a real rendered comparison,
not an illustrative mockup. Search terms include `unused air`, `pump timing`
and `πνιγεύς`.

The learner keeps the first pressure history, searches exactly seven strokes,
then allows unused air. At tank ratio 6 and one pipe the first domain has no
complete timing; the second has 22, and only three extra strokes are needed.
The difference comes from a changed constraint under the same explicitly modern
model. The review link is pinned to source revision `dea993263241af26ed5aad4561ea19736d6544c0`;
its raw bytes were compared with that Git object before browser navigation.

[Local catalogue receipt](pnigeus-timing-2026-11-05/local-catalogue.json): Chromium
and Firefox at 1440 and 375 px, local production catalogue to the actual public
Pnigeus lesson. Each journey searches all three terms, shares/restores the
filtered route, opens the pinned review by keyboard, opens the lesson by
keyboard and checks its fragment landing. It operates both search rules, saves
the actual editable notebook and illustrated reading, and activates the native
JSON download with scripts disabled. The downloaded notebook bytes agree.

After disabling browser networking, each journey reloads the lesson, imports
its saved notebook, exports another reading and opens Hero's retained Greek
page in full-page mode. The image decodes to its actual 1650-pixel width.
The public origin remains running during these catalogue checks; Pnigeus's
separate local audit stops its real test origin.

Reproduce after building the catalogue and starting its preview:

```sh
node scripts/pnigeus-timing-journeys.mjs http://127.0.0.1:4390/officina/ /tmp/pnigeus-catalogue
```

This document does not infer publication or hosted CI success from the local
catalogue journey. Public catalogue verification is recorded separately.
