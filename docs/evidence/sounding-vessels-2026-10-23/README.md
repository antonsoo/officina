# Discover the sounding vessels

The Gonia entry now leads to its published eighth room: thirteen sounding-vessel
positions, seven Greek pitch names, the unexpected upward step, and a separately
identified resonance model. The card retains architecture and flute search terms.
Its actual browser thumbnail shows the complete pitch trace beside the placements.

The local catalogue was exercised in Chromium and Firefox at 1280 and 375 pixels.
Each run searched both the new subject and an older keyword, followed the demo by
keyboard, changed a pitch, read the fourth-placement instruction, started and
stopped sound, detuned the resonator, and downloaded a WAV. The journey then
continued through the existing theatre, transport, column and source workflows.
The evidence link was opened by keyboard and its pinned heading reached through
native fragment navigation.

`local-journeys.json` records the local catalogue linked to the public lesson.
`thumbnails.json` identifies the actual public screenshot and its hash.
